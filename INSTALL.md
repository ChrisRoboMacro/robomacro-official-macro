# Install in Cursor / Grok Bot

Grok Bot uses the same Cursor plugin surface.

## Sideload

1. Copy this `plugin/` folder to `~/.cursor/plugins/local/robomacro-official-macro`
2. Reload the window
3. Enable **RoboMacro Official Macro**
4. MCP URL is `https://mcp.robomacro.com/mcp`

Ask: “Current federal funds rate” then “Show finance jobs on robomacro.com/jobs”. Teasers: “What's happening in China?” / “Which G10 currency is strongest?”
